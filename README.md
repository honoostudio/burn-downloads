# Burn Project — downloads

Instalador do Burn Project para Windows e pacote opcional de Bíblias livres.
Este repositório guarda só os arquivos de instalação. O código do programa não fica aqui.

**Versão mais nova:** veja em [Releases](https://github.com/honoostudio/burn-downloads/releases/latest)
(desde a 2.36.0 o instalador fica nas Releases, porque passa de 100 MB).

- `Burn Project Biblias livres.burnbib`: pacote opcional com 26 Bíblias livres
- `Burn Project 2.35.1.exe`: versão anterior (2.35.1)

Site: https://honoostudio.com/burn
